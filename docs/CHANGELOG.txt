MapKluss — Changelog
====================

v1.31.0
-------
- Cloud переработан в компактный рабочий экран: гостю остаются вход, скачивание мода и две короткие ссылки, а в аккаунте сразу открывается папка артов. Убраны повторяющиеся описания процесса, большая витрина мода и дублирующие действия.
- Плотная рабочая раскладка стала стандартной: боковые панели можно растягивать, а справа девять использованных материалов одновременно видны в сетке 3×3 рядом с палитрой; следующие группы листаются горизонтально. При расширении левая панель перестраивает размеры, дизеринг и коррекции в компактные сетки, а не растягивает длинные кнопки. Холст сохраняет минимальную рабочую ширину.
- Верхняя панель освобождена для рисования и масштаба; сетка, сравнение, текстуры блоков, предпросмотр, горячие клавиши и режим художника собраны в компактном блоке иконок внизу левой панели.
- Материал в ленте можно сразу найти в палитре, исключить или заменить на любой доступный блок через обычный безопасный пересчёт с Undo. Быстрые действия собраны в узкую вертикальную колонку на карточке.
- Рабочие блоки теперь всегда показывают максимум, нужный для одной карты, а не суммарное количество для всего арта.
- В палитре появилась компактная кнопка-фильтр: она показывает только цвета текущего набора. Выключенный уже после фильтра цвет остаётся видимым и его можно вернуть одним кликом.
- Круглые переключатели цветовых групп палитры заменены самими образцами цвета: яркий квадрат с лаймовой рамкой означает включённый цвет, затемнённый штрихованный — исключённый. Квадрат остаётся компактной кнопкой без лишнего текста.
- Разделитель «до/после» больше не включается при открытии редактора: сравнение остаётся ручным рабочим действием.
- Убраны повторяющие действия и обучающие пояснения вокруг основных настроек, чтобы обычный редактор тоже меньше прокручивался.
- Пипетка получает блок с холста и возвращает кисть; Shift + клик оставляет пипетку активной для серии быстрых выборок.
- У кисти, заливки и пипетки появился общий видимый выбор материала: текстура, название блока и цвет сразу видны после пипетки и используются всеми этими инструментами без повторного выбора.
- Shift + зажатая ЛКМ с пипеткой теперь выбирает материалы непрерывно: выбор обновляется только при переходе на новый пиксель.

v1.26.2 / Companion 0.11.1
--------------------------
- Файлы арта загружаются и проверяются ограниченно параллельно вместо последовательного ожидания каждого файла
- Cloud получает превью артов пакетами и параллельно собирает недавние арты, устраняя сотни внутренних запросов
- Смена приватности или повторное сохранение прежнего названия больше не запускает переименование всех артефактов
- Companion переиспользует HTTP-соединения и не скачивает уже актуальные обычные и многочастные Litematic
- Библиотека Companion показывает данные Cloud, не дожидаясь фоновой синхронизации схем; превью переиспользуются при обновлении signed URL
- Ускорены ZIP-экспорты: одиночная Litematic не строится второй раз, уже сжатые Litematic и map.dat не сжимаются повторно
- Редактор открывается без ожидания проверки gateway, а текстуры блоков загружаются только перед появлением в области просмотра
- Cloud собирает библиотеку, избранное и недавние арты из одного снимка; очистка Storage больше не задерживает ответ
- Проверка квоты выполняется один раз при резервировании сохранения вместо повторного пересчёта для каждого файла
- Companion не пересканирует неизменившиеся карты в открытом инвентаре каждые пять тиков
