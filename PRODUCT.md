# Product

## Register

product

## Users

Minecraft map-art builders who prepare images in a browser, export build files, and move projects between the MapKluss editor, Cloud, and the Companion mod. The primary workflow is repeated, detail-heavy production work rather than casual browsing.

## Product Purpose

MapKluss turns source images into practical Minecraft map-art projects and keeps the editor, saved library, build progress, exported artifacts, and in-game Companion workflow connected. Success means a builder can move from an image to a verified in-game result without losing fidelity, state, or time to manual file handling.

## Brand Personality

Technical, direct, crafted. The interface should feel like a focused Minecraft workshop: expressive enough to be recognizably MapKluss, but quiet and predictable while the user is editing.

## Anti-references

- Generic SaaS dashboards, oversized marketing heroes, soft glass cards, and decorative gradients.
- Interfaces that hide core editor controls behind unexplained gestures or ornamental motion.
- Minecraft styling reduced to noisy pixel-font decoration at the expense of readability.
- Public setup, debug, agent, or infrastructure copy mixed into the user experience.

## Design Principles

- Keep the editor as the primary screen and make the shortest common workflow visible.
- Use the existing sharp workshop language consistently across editor, Cloud, and public routes.
- Let artwork, previews, Minecraft blocks, and real project state carry the visual interest.
- Prefer precise, familiar controls and immediate state feedback over decorative UI.
- Preserve user work and make file, Cloud, and in-game transitions explicit and reversible.

## Accessibility & Inclusion

Keep Russian and English behavior synchronized, maintain keyboard and touch access, provide strong contrast, and never communicate state through color alone. Long-running or repeating motion must have a clear pause, dismiss, or equivalent control; nonessential transitions should respect reduced-motion preferences without breaking functional status displays.
